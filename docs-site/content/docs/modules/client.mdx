# 备份窗格

**本页回答**：窗格从哪儿拿数据、轮询停不停跟着什么走、灰灯为什么不是「没问题」。

`src/client/`。浏览器半，esbuild 打包、react 系外置（由页面的 importmap 解析到共享包，
插件之间拿同一份实例）。外壳先注本插件的 `style.css` 再 `import` 这份模块——样式表整张
scope 在本插件子树里，工具类只在自己那棵子树生效。

## 管什么

一个窗格（`mountPane`，id `main`）：状态灯与一句话、上次备份一行、两颗按钮（立即备份 /
立即检查）、五项自检逐项、数据目录一行。**不知道什么**：不知道备份在 node 那头怎么跑——
它只会调 `windows-backup.status` / `run` / `check` 三条命令；node 半的定时器（备份与自检
本体）跟这边毫无关系，**界面不在备份照跑**。

## 挂载契约

外壳调 `mountPane` 时给 `host`（命令桥）与 `pane`（窗格身份）；契约要求**同步**返回
`{ dispose }`——async / 回函数都算违约。未知窗格 id 出一行错而不是白屏。

## 轮询跟挂载走

取数走 `host.call('windows-backup.status')`，30 秒一轮；窗格被拆掉时 `dispose` 清掉
定时器。桥上的失败不炸窗格：桥断了窗格还在，留上一次的结论，下一轮轮询自然带回最新状态。

{/* ref file="../src/client/hooks.tsx" lines="30-42" */}

## 灰灯的口径

`report === null` 是「还没有结论」（挂上 30 秒后的第一次自检还没跑），**不是「没问题」**——
据此画灰灯；五项里的 `unknown` / `skipped` 同理画灰不画红。颜色守状态、动画归动画：
「正在跑」是灯的呼吸动画，不改变颜色。

## 提供的接口

对宿主外壳导出 `mountPane`。`view.ts` 是 `status` 回包的收窄与展示口径（形状的正本在
node 半 `snapshot()`，这头只按「用得上」收窄，不照抄全量字段）。

## 依赖的接口

| 接口 | 用来做什么 | 生产实现 | 测试实现 |
| --- | --- | --- | --- |
| `host.call` | 三条命令 | 外壳给的命令桥 | 假桥回固定状态 |
| react / react-dom | 渲染 | importmap 共享包 | 构建期外置 |

## 怎么单独测

`tests/mount.test.ts` 顺带盖住注册面（窗格 id、client/style 地址报给外壳）；`view.ts` 的
收窄与 `toneOf` 口径是纯函数，跟 node 半的回包样例对着测。浏览器半本身不起真页面——
typecheck 单独一份 tsconfig。
