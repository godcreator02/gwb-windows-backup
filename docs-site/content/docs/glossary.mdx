**本页回答**：文档里那个词在这个仓里到底指什么。收三类：仓自己造的词、通用词在这里有特定含义的、外来框架词；通用编程词不收。

## 备份

| 词 | 是什么 |
| --- | --- |
| **备份白名单** | 设置键 `sources`，一行一项（如 `D:/Notes`）。空则拒跑，不猜「整盘」这种默认 |
| **一轮** | 一次全流程备份：本地备份 →（每天一次）prune → OSS 备份 →（条件满足时）OSS prune → 写 state.json → 通知。见[备份管线](/docs/modules/pipeline) |
| **父快照** | 同一个仓里上一轮成功备份留下的快照：restic 拿它比对，没变的文件不读。本插件把它的 ID 记进 `state.json`、显式交给 `--parent`。见[备份管线](/docs/modules/pipeline#父快照) |
| **OSS 异地副本** | 对阿里云 OSS 上的 restic 仓库（`s3:` 地址）再独立备份一次，不是从本地仓拷快照；两个仓各有一条快照链 |
| **保留窗口** | forget 的保留参数：72 小时内全留、按日 14 天、按周 8 份、按月 12 份。见 [restic 封装与子进程](/docs/modules/restic) |
| **prune** | `restic forget --prune`：按保留窗口删旧快照并清掉不再被引用的数据。每天一次，真成功才记时间 |
| **补跑** | 加载 30 秒后看 `state.json` 的 `lastRunAt`：为空或离现在满一个周期，就先补一轮 |
| **陈旧锁** | 持锁进程不在了，或心跳停了超过 6 小时的 `backup.lock`，下一轮直接接管。见[锁](/docs/modules/lock) |
| **五项健康** | 上次备份 / 备份日志 / 磁盘余量 / 快照新鲜度 / 周期维护。见[五项健康](/docs/modules/health) |
| **日志契约行** | `Backup completed successfully` 那一族英文行：写日志与读日志两头认的是同一串字，只在 `messages.ts` 一处拼。见[日志契约与通知](/docs/modules/log) |
| **凭据纪律** | 密码只交路径（`--password-file`）、AccessKey 只进子进程环境变量；永不进设置、日志、异常消息。见[凭据纪律](/docs/modules/credentials) |
| **透传** | `windows-backup.restic` 命令：调用方给子命令与参数，本插件补 `--repo` 与 `--password-file`，密钥不出现在参数里 |

## 工作台

| 词 | 是什么 |
| --- | --- |
| **home** | 工作台的一套独立环境：一个普通的 npm 项目根，插件装在 `node_modules`，数据在 `data/` |
| **等待语义** | cordis 顶层 `inject` 的行为：列了的服务缺一个，整个插件不调用 `apply`、停在等待。所以顶层只列离了就没法备份的服务。见[宿主层](/docs/modules/host) |
| **局部注入** | `ctx.inject(['gwbShell'], …)`：服务在才调回调，缺了只是那一部分不跑 |
| **现读** | 设置每次用时重新读、不缓存：设置插件没有变更通知，缓存一份就会用旧值 |
| **窗格** | 外壳里的一块界面。本插件导出 `mountPane`，注册时报 `client` 与 `style` 的 `file://` 地址。见[备份窗格](/docs/modules/client) |

一个词进表的门槛：在两页以上出现，或者读者第一次见会问「这是什么」。改名是历史，写进轨迹卡。
