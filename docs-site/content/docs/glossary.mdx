站上正文里出现下面这些词时，构建时自动加一层标注，鼠标移上去显示定义；源文件里是干净的原词。
表的正本是站点根的 `docs-site/glossary.json`，一条一个 `term`、`def`、`href`（另有同义写法时加 `aliases`）。改词之前先看收词的判据：

- 收三类：这个仓自己造的词、通用词在这里有特定含义的、外来框架里读者容易看不懂的词
- 不收通用编程词，不收单字词：单字会命中一切，建索引时直接报错；两条术语不许抢同一个写法
- 定义只写概念，不写函数名、路径、设置键：这份数据里没法钉码，写进来就会过时而没人发现，具体的名字留给 `href` 指的那一页
