# 系统地图

**本页回答**：这个插件由哪几部分组成、一轮备份从头到尾经过哪些函数与文件、用户的哪些数据住在盘上哪个目录里。

## 三部分

| 部分 | 是什么 | 在哪 |
| --- | --- | --- |
| **域库** | 零第三方依赖、只用 node 内置模块的纯逻辑：锁、备份管线、五项健康、restic 封装、凭据解析、日志契约、配置收窄。可独立单测，不认识宿主 | `src/`（除 `src/client/` 与 `src/index.ts`） |
| **宿主层** | 把域库接到 gwb 内核上的那层：17 个设置键、六条命令、两个定时器、加载 30 秒后的首次自检与补跑、窗格注册 | `src/index.ts` |
| **窗格** | 备份窗格（本插件唯一的界面）：状态灯、五项、按钮、30 秒轮询。没装外壳的 home 里没有这部分，备份照常运行 | `src/client/` |

判据一句话：**代码只管「没有 AI 也要一直做」的事**——定时备份、周期自检、状态查看；一次性操作
（装 restic、换盘、USB 离机副本）归手册，不归代码。

## 一轮备份的路线

两种触发（定时器到点、`windows-backup.run` 命令）都进宿主层的同一个入口，再调域库
的 `runFullBackup`——锁在那里取，别的调用进不去：

```text
宿主层 runBackup（busy 挡同进程重入 → 现读配置 → refuseReason 拒跑判定）
  └→ runFullBackup（占 backup.lock，跨进程）
       ├→ doLocalBackup   restic backup --parent <state 里的本地快照 ID> → 本地仓库
       ├→ doPrune         forget+prune（每日一次，成了才记 lastPrune）
       ├→ doOssPush       第二次独立 restic backup，直接写 s3: 仓库（ossEnabled 时）
       ├→ doPrune(OSS)    OSS prune（本轮该 prune 且 OSS 推送成功才跑）
       ├→ logger.rotate   日志超阈值轮转
       ├→ writeState      lastRunAt / lastRunOk / lastRunSummary（成败都记）+ 两份父快照 ID
       └→ sendToast       Windows 通知（toast 设置开着时）
```

本地备份失败就整条停在第一步——本地都没成，OSS 推的是同一批源，多半也是同样的失败。
每一步在日志里写一行契约句（`Backup started` / `Prune FAILED with exit code N` 那一类），
健康检查的日志尾判定靠 grep 它们，见[日志契约与通知](/docs/modules/log)。

两次 `restic backup` 都从 `state.json` 取**父快照 ID** 显式传给 restic（本地仓库一份、OSS 仓库
一份，ID 不通用）。为什么要显式给：restic 默认按 `host,paths` 挑父快照，**白名单里加了
路径就是新组、一个候选都没有**，整份数据重读重算；给一份父快照，新路径当新文件读、其余路径
照旧只做比对。记着的 ID 在仓库里没了时（仓库重建、或 state 从更早的备份里恢复回来），撞上
restic 那句 `no matching ID found for prefix` 就不带父快照重跑一次——**这次重跑写的是普通说明
行，不是失败契约行**，见[备份管线](/docs/modules/pipeline)。

## 盘上有什么

全部用户私有数据住数据目录（宿主的 `gwbData.dir`，即 `<home>/data/<条目 id>`），代码树里
一个字节的用户数据都没有；隔离 home 有自己的数据目录，开发时碰不到真凭据。

| 路径 | 是什么 |
| --- | --- |
| `state.json` | 动作时间戳（上次备份、上次 prune、USB 副本、exclude 审计）加两份父快照 ID。坏了解析不了就当空，最坏多跑一次 prune |
| `backup.lock` | 进行中的备份那把锁（`{ pid, lease, startedAt, beatAt }`），跑完即删。见[锁](/docs/modules/lock) |
| `credentials/restic-password.txt` | 仓库密码。**内容永不读进本进程**，只把路径交给 restic |
| `credentials/oss-credentials.txt` | OSS AccessKey（KEY=VALUE 格式）。解析结果只进子进程 env |
| `bin/restic.exe` | restic 本体（`restic-exe` 设置指向它，相对路径按数据目录解析） |
| `logs/restic-backup.log` | 备份日志，超 10 MB 只留末 1000 行 |
