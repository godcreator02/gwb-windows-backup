## 提供

| 类别 | 名字 | 说明 |
| --- | --- | --- |
| 命令 | `windows-backup.run`、`check`、`status`、`paths`、`restic`、`mark` | 每条都标了 `effect`，参数与回执见[用法](/docs/usage#命令) |
| 设置键 | `sources`、`local-repo` 等十六个 | 经设置插件声明，见[用法](/docs/usage#设置) |
| 窗格 | `main`（标题「备份」，图标 `shield-check`） | 经外壳 `registerPane` 注册，只有装了外壳才有 |
| 显示名 | 「Windows 备份」，图标 `shield-check` | 经外壳 `describeSelf` 报 |
| 服务、事件、说明书 | 无 | |

## 注入

| 服务 | 提供方包 | 必需 / 局部注入 | peer 写法 | 用来做什么 | 缺了会怎样 |
| --- | --- | --- | --- | --- | --- |
| `gwbCommands` | `@godcreator/gwb-commands` | 必需（`export const inject`） | `^0.6.0` | 登记六条命令（0.6 起每条命令必须写 `effect`，没写登记时抛错） | 插件停在等待：cordis 等到它出现才调用 `apply`，备份也不跑 |
| `gwbSettings` | `@godcreator/gwb-settings` | 必需 | `^0.3.5` | 声明十六个设置键，每次现读 | 同上 |
| `gwbData` | `@godcreator/gwb-data` | 必需 | `^0.1.9` | 数据目录 `<home>/data/<条目 id>` | 同上 |
| `timer` | `@cordisjs/plugin-timer`（官方，公共 npm） | 必需 | `^1.1.3`（第三方 cordis 插件，和 gwb 插件一样写 peer） | `ctx.interval`：每分钟一跳 | 同上；插件管理不替它装，要单独 `plugin-manager.install`，没装时 `plugin-manager.list` 在本插件的 `unmetPeers` 里报出来 |
| `gwbShell` | `@godcreator/gwb-shell` | 局部注入 | `^0.15.1`，`optional: true` | 注册窗格、报显示名 | 没有窗格，备份与命令照常 |

内核包 `@godcreator/gwb-kernel-desktop` 的 peer 写 `^0.10.0`：node 侧只取 `GwbContext` 类型；浏览器侧的 react 由外壳提供，
经内核登记进页面的 importmap。本插件不按值 import `cordis`，peer 里没有它。

## 按名字调用与约定通道

本插件不按名字调用别的插件的命令，也不收发事件。窗格调的 `windows-backup.*` 是本插件自己的命令。

| 通道 | 对方 | 名字 | 用来做什么 |
| --- | --- | --- | --- |
| 子进程 | restic（数据目录 `bin/`，或设置键 `restic-exe` 指的位置） | `restic --repo <仓库> <子命令>`，凭据经本次 env 注入 | 备份、unlock、forget+prune、读最新快照、透传命令；argv 数组、不经 shell |
| 子进程 | Windows PowerShell 5.1 | `powershell -NoProfile -Command <WinRT 调用>` | 弹结束通知 |
| 代码调用 | `@godcreator/gwb-shell/browser-imports` | `browserImports()` | 构建时取浏览器侧外置模块名；外壳运行时登记 importmap 也调这个函数 |
| 读文件 | 本插件自己的包清单 | `../package.json`（相对 `dist/index.js`） | `status` 回执里的版本号 |
