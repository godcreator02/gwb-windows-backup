# 交接

**本页回答**：现在有什么活在路上、做到哪儿了、交给下一个会话要看什么。

这一区的规矩一句话：**有页 = 有活在路上，做完删**。一件活一页，页头是验收清单，正文是
实施方案；随做随提交，中途每次提交都是一份可交接的快照。做完把结论拆解归梁——设计进
[现状区](/docs)、决定落一张[轨迹卡](/trajectory)、没做的回[路线](/future/roadmap)——然后
把那一页删掉。git 历史是它的档案。

**此刻没有在途的活**——这一区只有这一页导读。侧栏上它旁边长出别的页，就是有活在路上。
四笔[未搬账](/future/roadmap)不算在途：它们各在等自己的前提，没开工。

## 什么样的活才升格成一页

**跨会话、跨模块、有未定选型**，三条占一条才写 spec；装得进一个会话的直接进模块页开工。
本仓的模块切得干净（域库零依赖、宿主层一层皮），大多数活装得进一个会话。
