# gwb-windows-backup

gwb 内核线的 Windows 备份插件（restic 快照 + OSS 异地 + 周期自检 + 备份窗格）。包名
`@godcreator/gwb-windows-backup`，发本机 Verdaccio（127.0.0.1:4873），装进 home 走手动
`pnpm add` + cordis.yml 条目。文档站 `docs-site/`，六区，dev 端口 4318。

## 门禁与跑法

```powershell
pnpm check      # typecheck ×2 + oxlint --deny-warnings + vitest(!slow)——提交前必绿
pnpm build      # tsc + esbuild + tailwindcss；tests/artifact.test.ts 守产物
cd docs-site && pnpm exec docfirst check   # 文档门禁，单独跑
```

发版走 devkit（说明书 `gwb-release` / `gwb-devkit`）：开发版 `devkit.dev` 发进隔离 home，
正式版 `devkit.release` 构建后自动上车检票——本仓没有自研发版脚本。

## 硬约束

- **`src/` 域库零第三方依赖**，node 内建 only；宿主层只认 `HostContext`，不 import 内核运行时
- **凭据纪律**：密码只交路径（`--password-file`）、OSS key 只进子进程 env；永不进设置、
  永不进日志、永不进异常消息
- **日志契约行只在 `src/messages.ts` 一处拼**——健康检查靠 grep 那几串英文，改一个词就把
  断备份读成一切正常
- **父快照两趟都显式递**（`state.json` 里的 ID → restic `--parent`），白名单加路径才不吃
  全量重读；那份 ID 失效时丢开父本重跑一次，**重跑那一跳不许写失败契约行**（`parentDroppedLine`
  刻意避开那四个关键词）
- **顶层 `inject` 只列 gwbCommands / gwbSettings / gwbData / timer**；外壳走局部注入，
  列顶层就等于 headless home 里备份整个挂起
- 所有 async 链自己 catch 并打日志——静默 reject 在日志里一根毛都不剩
- 两层并发保护缺一不可：闭包 `backing`（同进程）+ `backup.lock`（跨进程）
